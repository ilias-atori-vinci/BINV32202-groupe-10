Les profils, périodes et résultats individuels n'ont pas été consignés ; je ne les présente donc pas tous comme réussis.

## Précisions après relecture du 17 novembre 2026

La revue technique et les essais navigateur attribués à Codex sont décrits dans
[verification-seance-6.md](verification-seance-6.md) ; ils ne constituent pas mes
observations personnelles. Le relevé de consommation disponible est de 8 % : les
valeurs de début et de fin et le nombre absolu de crédits ne sont pas disponibles.

Pour mieux suivre l'agent lors des prochaines séances : demander une étape à la
fois, ouvrir chaque fichier du diff et expliquer le parcours page → hook → service
HTTP → API → SQL avant le commit. Il s'agit d'une méthode retenue pour la suite,
pas d'une vérification réalisée rétroactivement.
